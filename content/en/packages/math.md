# math {#math}

TeX math-mode typesetter → SVG via the OpenType MATH table; wasm-ready for offline math preview.

## Install {#install}

```bash
go get github.com/go-tex/math
```

Requires Go 1.26.4 or newer. `CGO_ENABLED=0`.
